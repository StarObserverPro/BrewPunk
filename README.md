# BrewPunk · 楼下酒局

一锅家酿，六个龙头。你在厨房里选麦芽、酒花、酵母和水，守一阵发酵桶，把酒装起来。到了自己定的日子先倒半杯，看看酒色，闻闻味，再把这一桶端给今晚来的人。

## 本地运行

需要 Node.js 20 或更新版本。仓库自带运行时模块和插画，运行与测试均无需安装依赖。

```sh
npm start
```

浏览器打开 <http://127.0.0.1:4189>。需要换端口时设置环境变量 `PORT`。也可以用任意静态 HTTP 服务提供仓库根目录。

```sh
npm test
npm run portable
```

第二条命令输出 `dist/BrewPunk.html`。在支持 ES 模块和 import maps 的现代浏览器里直接打开，厨房、酒房和本地评论都可离线运行。浏览器按当前地址保存手记；本地文件的存储可用性取决于浏览器设置。

当前界面采用全屏场景、半透明选择与读白、淡入淡出切换。酒房右侧逐条向上滚动当晚留言，支持暂停、继续和回看。厨房与发酵角接入 16 张工序状态图，14 类意外节点可在相应阶段出现。新开批次采用扩展工艺模型，既有批次按原模型续接。素材及验证记录见[本地集成说明](docs/novel-ui-integration.md)。

## 一桶的流程

1. 从浑浊 IPA、西岸 IPA、美式淡色艾尔、捷克淡色拉格、帝国世涛或酸 IPA 起步。默认一锅 25 L。改变麦芽、酒花、水质或酵母再开火。
2. 定糖化与投花程序，观察实际发酵情况，决定如何应对。可选增味、木桶接触和陈放，也可以直接进入分装。
3. 选生啤桶、玻璃瓶或罐，定储存温度和开喝的日子。先读杯中笔记，再查看带参照的风味标尺及 BJCP 模拟评分。
4. 把做好的酒放上酒房的一席，推进饮用和评论。满杯、分尝、续杯与留评分别记录。可以喝完归档，也可以提前收酒、把剩下的倒到墙根。打开旧酒牌可重读当时的笔记和留言。

酿造和品鉴各有一套带种子的蒙特卡洛。前者用同一配方反复酿，后者请不同客人品尝同一批酒。直接调用可参考 [完整链路测试](tests/integration.test.js)。
