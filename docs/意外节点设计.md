# 楼下酒局的意外节点

当前本地主线接通 14 类现场节点。每次先展示可观察的迹象，选择后再展示处置结果。快进停在未决选择前，刷新回到同一事件与分支。数值与概率为游戏参数，实现与验证见 [集成说明](novel-ui-integration.md)。

| 经过的物件与时机 | 迹象 | 玩家选择 | 后续落点 |
|---|---|---|---|
| 下料前的秤 | 零点漂移，实投少于酒单 | 校零补料／按实投继续 | 麦芽实投、比重和色度 |
| 糖化中的温度计 | 温度低于设定 | 补后半段温度／按当前火候继续 | 等效糖化温度与发酵结果 |
| 过滤时的液线 | 滤床排液变慢 | 松滤床慢排／接受少收一些 | 实际收液与供应体积 |
| 煮沸时的锅沿 | 泡沫上涌、麦汁溢出 | 降火再续煮／照原火候继续 | 保留已经发生的损失，减少后续损失 |
| 投酵前的冷却盘管 | 还未降到目标温度 | 继续冷却／按眼前温度投酵 | 最早半天的温度经历 |
| 第一晚后的桶温记录 | 实测高过设定线 | 换冰袋／观察 | 第一天实测保留，第二天温差随处置变化 |
| 活跃发酵时的气锁 | 泡沫进入气锁，排气断续 | 换排气管／继续观察 | 后续泡沫损失；异常与恢复使用不同状态图 |
| 干投袋 | 上半截未充分浸润 | 检查接触／按现状继续 | 后续酒花提取与香气 |
| 发酵末段取样杯 | 意料外的酸味 | 改用酸 IPA 对照／保留原申报 | 只改风格评审，酸味保留在酒中 |
| 木材接触中途取样 | 木香已经明显 | 现在离木／到原定日期 | 实际接触日数、木香与香气保留 |
| 分装转移管路 | 掠过一段空气 | 停下检查接口／照常转移 | 已有暴露保留，处置可减少后续摄氧 |
| 储存角落 | 环境温度升高 | 恢复冷藏／按当前环境放置 | 分段温度经历、开喝与后续出杯的香气 |
| 第一只开封容器 | 气泡或香气偏离预期 | 检查其余封口／记录后照常喝 | 首只样酒固定，其余容器封口风险改变 |
| 酒房首杯 | 泡沫特别多 | 冷却酒线再倒／接掉泡沫继续 | 当晚首杯损耗为 30／100 mL，按席号与夜次保留决定 |

同阶段可以有多件事，普通工艺镜头由玩家快进，需要决定的节点等待选择。事件取自批次、事件名称、容器编号或酒席夜次对应的固定随机流，重读、刷新与留言演出沿用已有结果。供应量使用实际收液量，已经分出的酒、已经发生的损耗与历史温度各自留账。

新锅使用扩展工艺模型。已经开始酿造的旧草稿及旧酒牌继续按原模型计算，尚未开火的草稿进入新流程。变更前面几步时清除相应后续处置，避免将上一次配方的补救带到新配方。

气锁安静可作为常规观察，是否异常应继续结合温度和发酵轨迹判断。逐次复尝、多温区精细储存和主动撤下一段封罐容器尚待后续扩展。
