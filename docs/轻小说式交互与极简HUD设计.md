# 《BrewPunk · 楼下酒局》轻小说式交互与极简 HUD 设计

设计稿 v1，供原型评审。依据本地版本 `5036af8` 的六步酿造、六席酒房与手记存档设计。

当前实现与本地验证见 [集成说明](novel-ui-integration.md)，意外节点的接通情况见 [节点表](意外节点设计.md)。

## 第一眼看到什么

厨房的窗开着，配方本压在秤盘旁边。桌角露着六张用旧的酒单。玩家点「翻开酒单」，挑中美式淡色艾尔，封面底下露出一张写着 25 L 的纸。可以直接照方开火，也可以在纸上改麦芽和酒花。点「照这张酿」以后，铅笔在方框里落下一勾，手把本子推到锅边。下一幕仍是这间厨房，炉火已经点着。

玩家以酿酒人的视角体验一锅酒。厨房以手和器物为主，第一次把镜头转向别人的脸，留给酒送下楼的那晚。画面占满主屏，时间和地点交给角标，玩家此刻能做什么，由场景里的一处动作和一句短文案交代。

### 主屏定稿方向

```text
┌──────────────────────────────────────────────────────┐
│ 发酵角落 · 第二天早晨                         手记  │
│                                                      │
│    窗框的影子落在地上。            ┌────┐            │
│                                    │温度│            │
│                      发酵桶        └────┘            │
│                          〔看一眼桶温〕              │
│                                                      │
└──────────────────────────────────────────────────────┘
```

线框中的环境描写和器物名称是给画师的标注。实际画面常驻两项 HUD：左上为场所与当前时段，右上为「手记」。时段只在有依据时出现，例如「分装后第 7 天」「酒房 · 第 2 晚」。桌沿、杯口等交互物旁至多出现一个主动作文字。点物件或文字效果相同，手机可把文字移到拇指可及的底边。第一次进入时直接露出动作，玩家无需猜热点。

| 此刻需要的信息 | 显示位置与时机 |
|---|---|
| 我手上是哪桶酒 | 酒名写在配方本、桶签和酒牌上。读数时将酒名随同读出。 |
| 我走到了哪一步 | 打开手记可看六步目录，当前页带书签。手记首页有「回厨房／去酒房」，保留两处各自的进度。 |
| 旁白、对白和继续 | 有文字时，底边浮起窄幅读白栏。旁白无姓名栏，酒客开口才出现署名。末尾的继续符号在句子完整后出现，读完收起整栏。 |
| 配方数值、杯数、评分 | 在相关物件上按需读。投花时看克数，开瓶时看品饮页，摸到酒牌才看当晚出杯。手记保留完整记录。 |

## 一次操作怎样演出来

普通操作依次经历「看见线索 → 做选择 → 手或器物有变化 → 回到可操作的场景」。一个决定占一张浮层。配方参数多时，用配方本作为可翻阅的整页，在相关条目里细调。翻手记、查看数值、重读留言均由玩家主动打开。

| 情形 | 出现方式 | 玩家怎样离开 |
|---|---|---|
| 普通选择 | 点场景动作后，读白栏上方展开选项。选项写具体动作，例如「换上冰袋」「先照常观察」。六种底方可在同一张酒单上浏览，点选可预看用料。 | 简单动作点一次即执行。配方、分装等复合决定先编辑草稿，最后用「照这张酿」「封好这批酒」提交。提交前可收起或改选。 |
| 可处置的意外 | 先给异常物件一个近景和实际读数，下一拍才出现应对选择。选择期间环境音延续，画面停在证据上。 | 等玩家明确选择，再播对应手势和后续结果。自动阅读和快进都停在选择前。 |
| 已发生的偏差 | 秤盘回不到零、管里掠过一段气泡，各占一个短镜头。玩家可以看记录，也可以接着做手头的事。 | 点继续回到本场。只给引擎能执行的补救动作，同一事件在后续章节通过手记回看。 |
| 日常反馈与跨日 | 小动作在原机位完成，例如瓶盖压下、秤盘落稳。跨日用同一构图匹配切换，例如酒标上的日期变化，光从窗的另一侧照进来。 | 短动作建议 0.3–0.6 秒，换景 0.6–1 秒。文字等玩家读完，跳过演出直接抵达结果帧。 |

逐字显示可关闭。文字还在出现时，第一次点按补全本句，下一次才推进；画面刚进入选择时须松开手指再选。日常反馈直接落在物件上，避免每次操作都要点一遍「知道了」。提前倒掉剩酒会结束供应，单独给出席号、酒名和后果，玩家确认后再演出摘牌。

## 一锅酒的七个场面

| 场面 | 玩家眼前的物件与决定 | 操作后的镜头 |
|---|---|---|
| 写酒单 | 配方本露出六种底方。选方后同页可取酒名、改批量，翻开配料页可换基础麦芽、水、酵母和拼配比例。 | 称好的谷物进盆，手写批签拴上盆把。后续镜头沿用这张批签。 |
| 糖化与煮沸 | 锅边夹着工艺单。「按方入桶」走默认程序；展开可改糖化温度、酒花品种和投放时机、克数与接触时间，也可安排干投、消毒和桶温。 | 插画按实际投放阶段演出。热端加投见花粒落锅，安排到第 5 天的干投先在桶签上圈日期，到那天才看见开桶。 |
| 巡发酵桶 | 桶壁留着泡沫线，点温度计查看。平顺批次只需读一眼即可继续；有异常时按发生顺序展示。 | 正常时手把温度计挂回去。夜间升温可换冰袋或记录后观察；末段酸味在取样时表现。 |
| 增味与陈放 | 砧板上挑原味或一种增味物，在桶签上选木材接触时长。 | 选樱桃，给一次果皮滚过刀背的近景；选原味，手盖上桶盖。选桶陈才出现木桶，翻到约定日期。 |
| 分装 | 台面上摆桶、瓶、罐，点一种，再填写转移方式、储温和开喝日。 | 压瓶盖、合罐盖或扣桶接头，用不同的手势和声响。日期写在容器上，随后切到同一标签的开喝日。 |
| 第一杯 | 杯子举到窗前，按杯中笔记的顺序读外观、闻香、入口和收口。可翻手记看风味标尺、申报风格与 BJCP 模拟评分。 | 泡帽落下，杯后露出自己的酒牌。「送下楼」接手拿酒牌下楼的镜头。换申报风格只更新评审页。 |
| 六席酒房 | 六个位置各有可辨编号和空满状态；桶接龙头，瓶罐占相应冷藏席。点酒牌选席、读当晚留言或再开一晚。 | 续杯就让原来的杯子再伸过来。若有人晚些时候留评，文字出现在署名留言上。收完最后一杯，可摘牌归档；玩家随时能回厨房酿下一锅。 |

上架前在吧台图中点空席。六席皆满时，玩家把新酒的牌子暂时夹回本子，可去看已有酒席或回到第一杯，草稿保留。冷门的一晚也成立：有人喝完没写字，镜头可以停在空杯和留着水印的杯垫上。人物举杯取自实际分杯记录，读评只显示截至当晚已发表的原文。厨房笔记、风格评审和酒客个人感受各有自己的入口。现有的两项 64 次模拟放在相应手记的附页。

## 可直接试排的一场：第一晚升温

取现有引擎的 25 L 美式淡色艾尔，设定 19 °C，随室温发酵，种子取 3，精确称量、认真消毒、密闭转移。这一锅只发生夜间升温。下表读数由该批次两种选择算得，画面和台词为拟稿；正式演出按当前批次取值。

| 拍 | 画面 | 屏上文字与交互 |
|---|---|---|
| 1 · 看见 | 第二天早晨，厨房全景。镜头不动，玩家碰一下桶旁的温度计。 | 场景动作「看一眼桶温」。 |
| 2 · 读数 | 切记录本特写。设定线在 19 °C，昨夜记录停在 22.6 °C；两条线有各自的文字标记。 | 「昨晚比设定高了 3.6 °C。冰袋还在冷冻格里。」读完浮出「换上冰袋」「先照常观察」。 |
| 3A · 换冰袋 | 手取出冰袋，擦掉袋上的霜，贴住桶壁。镜头停在手压平袋角的动作上。 | 「冰袋有点滑，我把它往桶底挪了挪。」光移到窗台另一侧，再读第二天记录，此时较设定高 0.9 °C。 |
| 3B · 照常观察 | 同一机位，手在本上圈出读数，把铅笔夹回书脊。 | 「我在刻度旁画了个圈，留着晚点对照。」同样切到当天稍晚，第二天记录仍较设定高 3.6 °C。 |
| 4 · 回来 | 两条路径回到同一桶边全景。A 的桶旁多了冰袋，B 的记录页上多了一圈铅笔印。 | 昨夜实测保留在两份手记里，下一动作都是「去增味台」。当天没有升温的批次从巡桶直接继续。 |

第一杯和酒房也沿用这个节奏，只是证据换了位置。举杯对光时，玩家先看杯子，再读这一杯的中性笔记；到酒房听到「我还想再来半杯」，必须有对应的分杯行为。若客人只在手机上发过短评，则用桌角手机亮起、署名文字浮现来演，避免把帖子写成当面说过的话。

## 画面、美术与小屏

保留现有厨房的窗向、木架和器皿位置。正式稿建议用暖灰线稿、低饱和水彩和少量厚涂光影。厨房的色彩留给麦汁、蒸汽里露出的铜锅和不同原料；入夜后转到深绿吧台，以桌灯照亮杯沿和酒客的手。读白用高对比的浅纸色底，角色姓名靠文字区分。第一人称旁白写眼前能看见、闻到或摸到的东西，能用手势说清的动作就留给画。

| 素材 | 原型先画什么 | 正式版值得加画什么 |
|---|---|---|
| 地点与时间 | 厨房、发酵角、酒房三张底景；窗框、桌沿建立连续性。 | 同机位晨光／夜灯变体、楼梯转角。用同一张酒牌从灶台接到楼下。 |
| 操作与意外 | 温度计读数、冰袋、两种手势与记录页，做完上述两条分镜。 | 加投酒花、封三种容器、取样闻酸、杯口第一圈泡沫各给一幅关键特写。 |
| 酒与酒客 | 酒液、透明度、泡层分别遮罩；吧台六席、一个熟客、一次递杯与一次留评。 | 给常客做可复用表情、手和衣物层；同桌分喝、续杯、安静离座用不同姿势。 |

桌面以横幅母版作全景，关键动作放在画面中部，读白栏贴底。手机竖屏另定取景：先保住手、器物和读数，再裁背景；读白与选择占下方自然流区域，长句可增高。六席若无法横排，则给一幅吧台总景，下面用两行各三张酒牌供选择。首次原型以 390 × 844 和 1280 × 720 两种尺寸检查同一场戏。读数有文本、音效有视觉对照；静音或启用减少动态效果时，首尾静帧和文字就能交代完整动作。

## 原型范围与验收

第一轮独立沙盒做两个可试玩片段：从巡桶到处理升温、稍后回看；从第一杯到点空席、读首晚留言。分别准备平顺、升温和当晚无人留言的数据。先用现有插画辨认场面，只精画桶边两种手势和下楼递酒牌；等选择节奏、手机构图通过试玩，再铺满七个场面。

- 初次进入，两种尺寸下都能看见眼下要做的动作，读出场所；普通游玩无需展开手记。只用触摸或键盘也能走通两段，焦点在浮层关闭后回到触发处。
- 连点、跳过或减少动态效果均抵达同一结果。事件选择不可被穿透；确认一次只写一次批次决定。上一段可从手记重读。上架前若需回改原配方，明确点「修改这锅」，只更新相应后续记录。
- 刷新未决事件时回到原选择；刷新已选结果时恢复结果或下一动作。保留批次种子和已选分支，既有手记按原批次、步骤、席号和场次续接。存档写入失败时，保留可见提示。
- 上架一次只占一席；满席可带着原草稿返回。重读、跳过送酒镜头或刷新均不重复上架、扣酒或推进夜次。无留言的场次依然可以开下一晚。
- 两个试玩者各自走一条升温分支，不翻数值总表，也能说出「昨夜发生了什么、自己做了什么、何时看见结果」。如果只记得点了哪个按钮，优先重排线索和结果镜头。
